PROJECT INFORMATION

About ReviewLens

A simple, transparent way to explore customer feedback.

r.

Feedback, made clearer.

ReviewLens is a browser-based customer review analysis project built for a BCA 5th semester project. It combines basic data cleaning, dictionary-based sentiment analysis and visual summaries in a static web app.

HTMLCSSJavaScriptChart.jsPapa ParseGitHub Pages

What it does

  • Loads sample data or a CSV file
  • Skips blank review text and handles invalid ratings
  • Classifies review sentiment with a small word dictionary
  • Calculates summary metrics and frequent words
  • Supports search, filters and CSV export

What it doesn't do

  • It does not train a machine learning model
  • It does not store data in a server database
  • It cannot reliably understand sarcasm or every context
  • It should not replace human review of important feedback
