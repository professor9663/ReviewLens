How to prepare your data

Three simple steps to get started

01—03
01 Put reviews in rows

Each row should represent one customer review. Keep the first row for column headings.

02 Include useful columns

Review text is essential. Product, rating, and date are optional but improve insights.

03 Confirm column mapping

ReviewLens detects common headings. Check the mapping before importing.

▤ Example CSV structure
review_text,product,rating,date
